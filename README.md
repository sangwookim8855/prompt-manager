# 📝 나만의 프롬프트 관리자 (Prompt Manager)

Python CLI 기반의 LLM 프롬프트 관리 프로그램입니다. 
다양한 프롬프트를 저장하고 카테고리별 조회, 키워드 검색, 즐겨찾기 등의 기능을 제공합니다.

## 🚀 주요 기능
1. **전체 프롬프트 목록 보기**: 등록된 모든 프롬프트의 ID, 카테고리, 제목 조회
2. **프롬프트 상세보기**: 특정 프롬프트의 상세 내용 출력
3. **새 프롬프트 추가**: 새로운 프롬프트 등록
4. **카테고리별 조회**: 카테고리별 필터링 기능
5. **키워드 검색**: 제목 및 내용 기준 키워드 검색
6. **즐겨찾기 관리**: 즐겨찾기 토글(등록/해제) 및 즐겨찾기 목록 조회
